# Mathesis — Математическая база знаний и нейросимволический конвейер

**Mathesis** — это комплексный программный инструментарий для автоматизированного извлечения, формализации и структуризации математических знаний (определений, теорем, аксиом, свойств) непосредственно из учебных материалов. Система строит динамический граф логических зависимостей, прослеживая каждое утверждение вплоть до фундаментальной системы аксиом Zermelo-Fraenkel (ZFC).

---

## 🚀 Быстрый старт

### 1. Активация виртуального окружения

В корневой директории проекта уже настроено виртуальное окружение. Активируйте его в зависимости от вашей операционной системы:

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

---

### 2. Установка зависимостей

Установите необходимые пакеты с помощью `pip`:
```bash
pip install -r requirements.txt
```

> [!NOTE]  
> Если вы планируете запускать LLM-экстрактор (агент) на базе Google Gemini, дополнительно установите:
> ```bash
> pip install google-genai pillow python-dotenv
> ```
> И не забудьте настроить ключ `GEMINI_API_KEY` в файле `.env`.

---

### 3. Запуск веб-сервера 🖥️

Для запуска веб-интерфейса (интерактивного компилятора и каталога сущностей) используйте **Uvicorn**:

```bash
uvicorn web.app:app --reload
```

После успешного запуска откройте в браузере:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

---

### 4. Генерация полной документации (сборка книги) 📚

Чтобы собрать полную PDF-книгу со всеми сущностями графа, их описаниями на естественном языке (RU/EN) и формулировками LaTeX, запустите:

```bash
python pipeline/generate_full_book.py
```
*Собранная книга будет доступна по пути: `output/full_book.pdf`*

---

### 5. Дедупликация и проверка эквивалентности сущностей 🔄

Если в базе накопились дубликаты или схожие утверждения, запустите модуль семантического слияния. Он найдет синтаксические и семантические дубликаты, а также очистит сиротские артефакты:

```bash
python pipeline/postprocess_equivalence.py
```

### 6. Запуск конвейера извлечения и Lean-валидации 🧠

Главный скрипт `pipeline/ollama_wrapper.py` поддерживает гибкую маршрутизацию задач между разными LLM-моделями (как локальными, так и облачными) для каждого этапа конвейера. Это позволяет использовать мощные модели (например, Gemini или OpenAI) для сложного синтеза и дешевые локальные модели (например, Ollama/llama.cpp) для рутинных задач.

**Пример сложного запуска с гибридной маршрутизацией:**
```bash
python pipeline/ollama_wrapper.py "Определение равномерно непрерывной функции" \
  --cv-model qwen3-vl:4b \
  --extract-preview-provider llama_cpp \
  --extract-preview-model "llama/bge-reranker-v2-m3-Q6_K.gguf" \
  --extract-provider gemini \
  --extract-model gemini-3.1-flash-lite \
  --synth-provider gemini \
  --synth-model gemini-3.1-flash-lite \
  --lean-provider ollama \
  --lean-model "goedel:latest" \
  --embed-provider ollama \
  --embed-model "nomic-embed-text:latest"
```

#### Доступные модули и аргументы:

Конвейер позволяет переопределить провайдера (`-provider`), модель (`-model`) и API-ключ (`-api-key`) индивидуально для каждого логического модуля:

* **Глобальные настройки:** `--provider`, `--model`, `--api-key` (применяются ко всем модулям по умолчанию).
* **`--extract-...`** — Модуль извлечения (Чтение PDF и извлечение сырого математического текста). 
* **`--extract-preview-...`** — Модуль предварительного фильтра (Быстрый поиск и фильтрация релевантных страниц с помощью reranker моделей или быстрых локальных LLM).
* **`--synth-...`** — Модуль синтеза (Трансляция извлеченного текста в строгий канонический LaTeX, дедупликация и объединение источников). Требует самой умной модели (Gemini/GPT-4).
* **`--lean-...`** — Модуль формализации (Генерация кода на Lean 4 для проверки логики). Отлично работают специализированные локальные модели (например, Goedel/InternLM).
* **`--embed-...`** — Модуль эмбеддингов (Векторный поиск для разрешения сущностей и зависимостей).
* **`--cv-model`** — Выбор модели компьютерного зрения / OCR (например, `qwen3-vl:4b` или `glm-ocr`) для распознавания формул в PDF.

**Полезные флаги:**
* `--force-refresh`: Принудительно очищает кэш извлеченных формулировок и заставляет конвейер заново обработать текст учебников (не удаляет сами сущности из БД).
* `--no-validate`: Отключает этап компиляции Lean 4, ускоряя генерацию графа LaTeX (полезно при отладке).
* `--ocr-pages`: Обрабатывать только конкретные страницы, игнорируя предварительный поиск. Формат: `--ocr-pages '{"book": "zorich", "pages": [1, 2, 3]}'`.

### 7. Использование отдельных утилит конвейера 🛠️

В процессе работы над базой знаний иногда требуется запустить отдельные скрипты вручную:

* **Сборка PDF для одной или нескольких сущностей** (включая все их зависимости):
  ```bash
  python pipeline/generate_answer.py --roots "prop-cantor-uniform-continuity"
  ```
  *Результат сохраняется в `output/result.pdf`*

* **Генерация макросов LaTeX** (обновляет `mathesis_macros.sty` на основе метаданных `% macro:` из `content/`):
  ```bash
  python pipeline/generate_macros.py
  ```

* **Актуализация базы данных** (если вы вручную отредактировали `.tex` файлы в папке `content/`, эта команда обновит их в `mathesis_index.db`):
  ```bash
  python pipeline/actualize_db.py
  ```

## 📂 Структура проекта

Основные модули и папки проекта:

* **`web/`** — веб-интерфейс на FastAPI и шаблонах Jinja2 с рендерингом KaTeX для математических формул.
  * `web/app.py` — основной файл приложения FastAPI.
  * `web/templates/` — HTML-шаблоны для каталога и компилятора.
  * `web/static/` — CSS-стили, JS-скрипты и статичные ресурсы.
* **`pipeline/`** — конвейер нейросимволической обработки (экстракция сущностей с помощью LLM, Lean-валидация, трансляция).
* **`mathesis/`** — ядро системы (MathesisDB API, интерфейс к базе данных SQLite `mathesis_index.db`).
* **`docs/`** — подробная техническая документация и руководства разработчика.
* **`tools/`** — вспомогательные скрипты, компиляторы LaTeX (`build.bat`) и утилита `cloudflared` для быстрого туннелирования.
* **`content/`** — исходные файлы математического контента в формате LaTeX.

## 🛠️ Основные возможности

1. **Интерактивный веб-компилятор**: Возможность компиляции выбранных фрагментов теории или результатов запросов к LLM в полноценные PDF-документы в реальном времени.
2. **База знаний (Knowledge Graph)**: Быстрый поиск и навигация по графу зависимостей (аксиомы ➔ объекты ➔ свойства ➔ операции ➔ теоремы).
3. **Lean Validation**: Валидация формализованных утверждений в среде Lean 4 для обеспечения математической строгости.
4. **Интеграция с Cloudflare Tunnel**: Автоматический запуск публичного туннеля для совместной демонстрации или удалённого тестирования.
