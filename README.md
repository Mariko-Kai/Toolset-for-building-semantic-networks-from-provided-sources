# Mathesis — Математическая база знаний и нейросимволический конвейер

**Mathesis** — это комплексный программный инструментарий для автоматизированного извлечения, формализации и структуризации математических знаний (определений, теорем, аксиом, свойств) непосредственно из учебных материалов. Система строит динамический граф логических зависимостей, прослеживая каждое утверждение вплоть до фундаментальной системы аксиом Zermelo-Fraenkel (ZFC).

---

## 🚀 Быстрый старт

### 1. Активация виртуального окружения

В корневой директории проекта уже настроено виртуальное окружение. Активируйте его в зависимости от вашей операционной системы:

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

---

### 2. Установка зависимостей

Установите необходимые пакеты с помощью `pip`:
```bash
pip install -r requirements.txt
```

> [!NOTE]  
> Если вы планируете запускать LLM-экстрактор (агент) на базе Google Gemini, дополнительно установите:
> ```bash
> pip install google-genai pillow python-dotenv
> ```
> И не забудьте настроить ключ `GEMINI_API_KEY` в файле `.env`.

---

### 3. Запуск веб-сервера 🖥️

Для запуска веб-интерфейса (интерактивного компилятора и каталога сущностей) используйте **Uvicorn**:

```bash
uvicorn web.app:app --reload
```

После успешного запуска откройте в браузере:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

## 📂 Структура проекта

Основные модули и папки проекта:

* **`web/`** — веб-интерфейс на FastAPI и шаблонах Jinja2 с рендерингом KaTeX для математических формул.
  * `web/app.py` — основной файл приложения FastAPI.
  * `web/templates/` — HTML-шаблоны для каталога и компилятора.
  * `web/static/` — CSS-стили, JS-скрипты и статичные ресурсы.
* **`pipeline/`** — конвейер нейросимволической обработки (экстракция сущностей с помощью LLM, Lean-валидация, трансляция).
* **`mathesis/`** — ядро системы (MathesisDB API, интерфейс к базе данных SQLite `mathesis_index.db`).
* **`docs/`** — подробная техническая документация и руководства разработчика.
* **`tools/`** — вспомогательные скрипты, компиляторы LaTeX (`build.bat`) и утилита `cloudflared` для быстрого туннелирования.
* **`content/`** — исходные файлы математического контента в формате LaTeX.

## 🛠️ Основные возможности

1. **Интерактивный веб-компилятор**: Возможность компиляции выбранных фрагментов теории или результатов запросов к LLM в полноценные PDF-документы в реальном времени.
2. **База знаний (Knowledge Graph)**: Быстрый поиск и навигация по графу зависимостей (аксиомы ➔ объекты ➔ свойства ➔ операции ➔ теоремы).
3. **Lean Validation**: Валидация формализованных утверждений в среде Lean 4 для обеспечения математической строгости.
4. **Интеграция с Cloudflare Tunnel**: Автоматический запуск публичного туннеля для совместной демонстрации или удалённого тестирования.
