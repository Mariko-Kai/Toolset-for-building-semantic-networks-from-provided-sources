\begin{object}[term-set] % \Set{Множество} (Set)



\textbf{Описание:}
Фундаментальный объект теории \Set{множеств} Цермело-Френкеля. \Set{Множество} — это совокупность объектов, обладающих общим свойством, рассматриваемая как единое целое.

\textbf{Аксиоматика:}
Свойства \Set{множеств} полностью определяются аксиомами \ZfcExtensionality{объемности}, \ZfcPairing{пары}, \ZfcUnion{объединения} и др.

\textbf{Базовое отношение:}
Основным отношением является принадлежность элементу $x \in A$.
\end{object}
