\begin{object}[obj-set] % Множество (Set)
\textbf{Описание:}
Фундаментальный объект теории множеств Цермело-Френкеля. Множество — это совокупность объектов, обладающих общим свойством, рассматриваемая как единое целое.

\textbf{Аксиоматика:}
Свойства множеств полностью определяются аксиомами \entityref{axm-zfc-extensionality}{объемности}, \entityref{axm-zfc-pairing}{пары}, \entityref{axm-zfc-union}{объединения} и др.
\end{object}
