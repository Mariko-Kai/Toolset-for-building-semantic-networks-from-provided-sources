# Mathesis — Mathematical Knowledge Base

Добро пожаловать в документацию проекта **Mathesis**.

---

## Назначение проекта

Mathesis — это программный комплекс для автоматизированного **извлечения**, **формализации** и **структуризации** математических сущностей из учебников. Система строит граф зависимостей между формулировками, прослеживая их до выбранной системы аксиом (по умолчанию — ZFC).

---

## Модули системы

| №  | Модуль | Описание |
|----|--------|----------|
| 1  | **Content Extractor** | Выделяет сущности из учебников (объекты, свойства, операции, теоремы, аксиомы), классифицирует их и строит связи вплоть до системы аксиом ZFC. |
| 2  | **Formalizer** | Переписывает формулировки сущностей в формальном виде без использования естественного языка. |
| 3  | **Parser / Indexer** | Парсит полученный LaTeX-контент в базу данных SQLite для дальнейшей работы через API. |
| 4  | **MathesisDB API** | Единая точка входа (фасад) для работы с базой данных: CRUD, поиск, валидация, навигация по графу. |
| 5  | **Транспорты** | Web-интерфейс (FastAPI + KaTeX), CLI, Desktop (в будущем). |
