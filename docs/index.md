# Mathesis — Mathematical Knowledge Base

Добро пожаловать в документацию проекта **Mathesis**.

---

## Назначение проекта

Mathesis — это программный комплекс для автоматизированного **извлечения**, **формализации** и **структуризации** математических знаний из учебников с их последующей строгой верификацией. Система строит направленный граф зависимостей между определениями, свойствами, операциями и теоремами, вплоть до базовых аксиом (по умолчанию ZFC).

Проект делает упор на формальную математическую строгость: все извлечённые знания проверяются автоматическим прувером Lean 4, а дублирующиеся сущности объединяются на основе доказанной семантической эквивалентности.

---

## Ключевые модули системы

| №  | Модуль | Описание |
|----|--------|----------|
| 1  | **Modular Extraction Pipeline** | Модульный конвейер извлечения (с поддержкой Gemini и локальных моделей Ollama), который читает сканированные страницы, выделяет математические утверждения и разрешает неявные контексты (Ensemble Extractor). |
| 2  | **Two-Tier Hybrid Search** | Двухуровневая стратегия поиска (Hybrid Search). Быстрый Preview LLM отсеивает нерелевантные страницы, после чего тяжелая модель извлекает математический смысл. |
| 3  | **Canonical Synthesizer** | Синтезирует строгие LaTeX-файлы с функциональной нотацией и топологически сортирует их для построения единого `master.tex`. Поддерживает генерацию конечного `full_book.tex`. |
| 4  | **Lean 4 Validator Pipeline** | Автоматически переводит математические формулы в код Lean 4 и запускает валидацию и поиск доказательств с помощью агента Goedel (LLM-ассистент). Сохраняет успешные коды в `output/lean`. |
| 5  | **Entity Alignment Tooling** | Модуль семантического слияния (`postprocess_equivalence.py`). Использует векторные представления (Embeddings) для поиска дубликатов и доказывает их эквивалентность через Lean 4. |
| 6  | **Web Compiler Interface** | Веб-приложение (FastAPI) с фронтендом для интерактивного просмотра графа, компиляции батчей и управления базой данных `mathesis_index.db`. |
