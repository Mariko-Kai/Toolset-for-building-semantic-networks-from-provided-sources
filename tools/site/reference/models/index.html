    mathesis.models¶

    Все модели данных — чистые dataclass-ы без ORM-зависимостей. Используются для ввода/вывода через MathesisDB.

    mathesis.models ¶

    Data models for mathesis entities.

    All models are plain dataclasses — no ORM dependency. Core module uses these for input/output; transports serialize them as needed.

    @dataclass
class ObjectComposition:
    """Container object (space) is composed of components."""
    container_id: str = ""
    obj_comp_id: Optional[str] = None
    prop_comp_id: Optional[str] = None
    op_comp_id: Optional[str] = None
    role: str = ""                  # 'base_set' | 'structure' | 'axiom'

    @property
    def component_id(self) -> str:
        return self.obj_comp_id or self.prop_comp_id or self.op_comp_id or ""

    @property
    def component_type(self) -> str:
        if self.obj_comp_id:
            return "object"
        if self.prop_comp_id:
            return "property"
        if self.op_comp_id:
            return "operation"
        return ""
